# Base Pygame - Plateforme

Installation :

pip install pygame-ce

Lancement :

python main.py

Touches :
- Q / Flèche gauche
- D / Flèche droite
- Espace / Flèche haut : saut

Le sprite du joueur est placé dans :
assets/sprites/joueur.png

Toute la logique du personnage est centralisée dans :
game/joueur.py
